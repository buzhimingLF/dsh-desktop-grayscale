# Release checklist / 安装器发布检查表

This checklist keeps the public GitHub Release aligned with the actual DSH
Desktop workbench. It is intentionally short enough to run for every release.

这份检查表用于保证 GitHub Release 与实际 DSH Desktop 工作台一致；每次发布都应执行。

## Version and source / 版本与源码

- [ ] `app/package.json` version is the release version.
- [ ] The pushed tag is exactly `v<app/package.json version>`.
- [ ] `pnpm install --frozen-lockfile` succeeds in `app/`.
- [ ] `pnpm typecheck` succeeds.
- [ ] `pnpm verify:runtime` reports DSH `0.1.0-rc.6` and all expected packages.
- [ ] `pnpm build` succeeds.
- [ ] `node scripts/verify-see-skills.mjs` succeeds.
- [ ] `node --test plugins/fork/dsh-routing-suite/test/*.test.mjs` succeeds.

## Product contract / 产品契约

- [ ] A clean profile starts the official `dsh web` runtime and the Electron window.
- [ ] The default surface is minimal grayscale with glass depth, including background,
      editor, and terminal layers.
- [ ] The Agent selector exposes `routing-suite` Smart routing.
- [ ] `GET /routing-suite/api/status` returns HTTP 200 when that mode is selected.
- [ ] The Skills tab and `GET /see-skills/skills` expose structured skill records.
- [ ] `$DSH_HOME/skills`, `~/.agents/skills`, and `~/.codex/skills` are discoverable.
- [ ] No user credential, private Skills body, `.env`, key, certificate, or token is in the commit.

## Installer smoke test / 安装包冒烟测试

- [ ] The target platform installer is generated by `pnpm dist`.
- [ ] The package contains Electron, `dsh-runtime/node_modules`, `dsh-routing-suite`,
      `dsh-see-skills`, and `dsh-skin-grayscale`.
- [ ] A fresh user-data/profile launch completes; one first-run runtime restart is acceptable.
- [ ] No Node.js, pnpm, or global `dsh` installation is required.
- [ ] Release notes state that packages are unsigned and that Provider/model credentials
      remain a user responsibility.

## Supported assets / 支持的安装包

| Platform / 平台 | Assets / 包 |
|---|---|
| Windows x64 | NSIS `.exe` |
| macOS Intel / Apple Silicon | `.dmg` + `.zip` |
| Linux x64 | `.AppImage` + `.deb` |

The GitHub Actions release matrix builds each platform on its native runner. A
Windows workstation can validate the Windows installer locally; macOS and Linux
assets must be validated by their native CI jobs before publishing.

GitHub Actions 使用各平台原生 runner 构建。Windows 本机可以验证 Windows 安装器；
macOS/Linux 包应以对应 CI job 成功作为发布前提。
